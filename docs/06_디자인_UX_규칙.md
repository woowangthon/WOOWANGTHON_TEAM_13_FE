# 06. 디자인 · UX 규칙

디자인 값(색 · 글꼴 · 간격 · 모서리)과 `src/ui/` 부품은 **나현**이 정한다. 화면을 만들 때는 `src/ui/` 부품을 가져다 쓰고, 색이나 크기를 화면마다 따로 정하지 않는다.

## 화면 크기
- 알바 화면: **모바일 기준 (폭 360~430px)**, 하단 탭 5칸 — 🏠 홈 · ☕ 레시피(매뉴얼 포함) · ＋ 인수인계 남기기 · 💬 AI 사수 · 🗓 근무 (아이콘 아래 글자)
- 사장 화면: **모바일 우선 + 데스크톱(1024px 이상)은 대시보드** — 휴대폰 · 태블릿은 모바일 화면(가운데 460px) 그대로, 1024px 이상은 왼쪽 메뉴(하단 탭 대신) + 넓은 본문(최대 1180px, 한 줄 목록 화면은 760px). 홈은 왼쪽 큰 칸 + 오른쪽 칸 대시보드, 시트는 가운데 대화창 (11/13 변경, 예전: 최대 폭 768px)
- 터치 영역은 최소 44px

## 화면 상태 4가지 (모든 화면 공통)
| 상태 | 쓰는 부품 | 예시 문구 |
| --- | --- | --- |
| 불러오는 중 | `ui/Spinner` | — |
| 데이터 없음 | `ui/EmptyState` (안내 + 다음 행동은 `shared/EmptyGuide`) | "아직 등록된 레시피가 없어요" + "사장님이 레시피를 등록하면 여기에 보여요" + [AI 사수에게 묻기] |
| 에러 | `ui/Toast` (빨간색) + 다시 시도 | "불러오지 못했어요. 다시 시도해 주세요" |
| 성공 | `ui/Toast` | "저장했어요" |

## 문구 말투
- 존댓말 **"~해요"** 체로 통일: "저장했어요", "다시 확인해 주세요", "사장님께 전달했어요"
- 버튼은 짧게: 저장 / 취소 / 삭제 / 다음 / 확인
- 딱딱한 말 대신 쉬운 말: ❌ "데이터 처리 완료" → ⭕ "저장했어요"

## AI 화면 규칙
- AI 답변에는 **항상 출처 카드** (📄 출처: 레시피 › 딸기라떼)
- 근거가 없으면 "매뉴얼에서 찾지 못했어요. 제가 지어내지 않을게요" + [사장님께 물어보기]
- AI가 만든 결과(레시피 사진 스캔, 인수인계 요약)는 사람이 **확인 · 수정**할 수 있게
- 금액은 항상 "참고용" 표시

## 표시 형식 (`src/lib/format.ts`)
- 날짜 `11/20(금)` · 시간 `18:00` · 금액 `681,120원`

- 빈 화면 점검용 매장 **새싹 카페** (초대코드 `N4EW7K`): 레시피 · 매뉴얼 · 인수인계 · 채팅 · 근무 · 급여가 하나도 없는 새 매장. 초대코드로 들어가야만 보여요
