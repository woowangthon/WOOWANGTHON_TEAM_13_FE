# 04. 화면 · 파일 · 주소

🟠 민지 / 🟣 나현 / 🤖 자동. **남의 폴더는 수정 금지, import는 OK.** 파일 이름 · 주소를 바꿔야 하면 FE끼리 먼저 토의하고, **바꾼 PR에서 이 문서도 같이 고친다.**


## 이름 규칙
- 화면: `○○Page.tsx` (default export) · 부품: `PascalCase.tsx` (named export) · 함수 · 변수: `camelCase`
- 주소: 알바 `/staff/...`, 사장 `/owner/...`, 공통 `/login` · `/auth/callback` · `/role`
- 가짜 데이터: `api/mocks/staff/recipes.ts`처럼 BE 기능 이름 그대로
