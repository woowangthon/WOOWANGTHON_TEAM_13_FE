# 04. 화면 · 파일 · 주소

🟠 민지 / 🟣 나현 / 🤖 자동. **남의 폴더는 수정 금지, import는 OK.** 파일 이름 · 주소를 바꿔야 하면 FE끼리 먼저 토의하고, **바꾼 PR에서 이 문서도 같이 고친다.**

## 폴더 구조
```
src/
├─ main.tsx              🟠
├─ index.css             🟣 전역 스타일 · 디자인 토큰 (Tailwind)
├─ app/                  🟠 App · providers · AuthBootstrap(앱 시작 시 로그인 확인) · router · guards · PagePlaceholder · NotFoundPage
├─ lib/                  🟠 env · auth · authStore · storeStore · apiClient · kakao · format · date(API 날짜 ↔ Date)
│  └─ api/               🟠 데이터 훅 · API 타입 (types · errors(에러 공통 처리) · users(내 정보 · 내 매장) · invitations(초대코드) · schedule(근무) · recipes · manuals · assistantChat · handover). 화면은 가짜 데이터 대신 이 훅을 쓴다 (사장 화면도 import)
├─ api/
│  ├─ generated/         🤖 npm run api 로 자동 생성 (직접 수정 금지)
│  └─ mocks/             staff/ 🟠 (초대코드 · 들어간 매장 join.ts 포함, api/ 가짜 서버: docs/07 모양으로 돌려줌) · owner/ 🟣 (BE 준비 전 가짜 데이터)
├─ ui/                   🟣 디자인 시스템 (Button · IconButton · Card · Badge · Chip · Tabs · Header · BottomNav · BottomSheet · Input · Textarea · Switch · Calendar · Toast · EmptyState · Spinner · utils)
├─ shared/               🟠 사장 · 알바 화면이 같이 쓰는 보기용 부품 (데이터 · 이동 주소는 props로 받는다)
│  ├─ icons.ts           카테고리 · 매뉴얼 · 매장 아이콘, 카테고리 · 인수인계 태그 색
│  ├─ storeTheme.ts      매장 테마 키(moon · sunset) → 매장 색 · 연한 색 · 사진 그라데이션
│  ├─ recipe/            CategoryTabs · RecipeGrid · RecipeCard
│  ├─ manual/            ManualCard · ManualGrid
│  ├─ handover/          HandoverList · HandoverItem · HandoverWriteForm · AiSummaryCard
│  └─ store/             StoreSwitcher(매장 목록 시트) · StoreAvatar
└─ pages/
   ├─ auth/              🟠 (components/AuthFrame 로그인 화면 틀 · OnboardingHeader 역할 선택 · 초대코드 상단 · ProviderLogo 카카오 · 구글 로고 · assets/ 로그인 사진, 디자인 시안 docs/design/login-onboarding.html)
   ├─ staff/             🟠 (components/ 알바 공통 부품 · staffStore · useCurrentStore · useProfileName · useCloseTo)
   └─ owner/             🟣
```

## 이름 규칙
- 화면: `○○Page.tsx` (default export) · 부품: `PascalCase.tsx` (named export) · 함수 · 변수: `camelCase`
- 주소: 알바 `/staff/...`, 사장 `/owner/...`, 공통 `/login` · `/auth/callback` · `/role`
- 가짜 데이터: `api/mocks/staff/recipes.ts`처럼 BE 기능 이름 그대로
