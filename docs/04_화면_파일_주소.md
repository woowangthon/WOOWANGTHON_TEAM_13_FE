# 04. 화면 · 파일 · 주소

> 서비스 이름: **crewBean** (c 소문자 · B 대문자, 11/10 회의). AI 채팅 기능 이름은 그대로 **AI 사수** (하단 탭 · "AI 사수에게 묻기"). 아이콘 · 파비콘: `public/` favicon.svg · favicon.ico · apple-touch-icon.png · icon-192.png · icon-512.png (나현) → `index.html` 링크(`?v=2`, 아이콘을 바꾸면 숫자를 올려 브라우저 캐시 무시) · `vite.config.ts` PWA manifest icons (민지). maskable 아이콘은 아직 없음 (배경이 꽉 찬 · 여백 있는 그림이 따로 필요).

🟠 민지 / 🟣 나현 / 🤖 자동. **남의 폴더는 수정 금지, import는 OK.** 파일 이름 · 주소를 바꿔야 하면 FE끼리 먼저 토의하고, **바꾼 PR에서 이 문서도 같이 고친다.**

## 앱 사용법 공용 틀 (`src/shared/guide/GuideSlides.tsx`)

사장 · 알바 앱 사용법이 같은 모양이 되도록 카드 넘기기 틀만 공용으로 둔다. 알바 버전: `pages/staff/guide/StaffGuidePage.tsx` · 사장 버전: `pages/owner/guide/OwnerGuidePage.tsx`.

```tsx
<GuideSlides
  slides={[
    { tab: '홈', title: '출근하면 인수인계부터 확인해요', body: '설명 2줄 이내', visual: <그림 /> },
    // …
  ]}
  onDone={() => navigate('/owner', { replace: true })} // [건너뛰기] · 마지막 버튼 둘 다 onDone
  doneLabel="시작하기" // 마지막 장 버튼 (기본 "시작하기")
/>
```

- 전체 화면(하단 탭 없음): 위 [건너뛰기](마지막 장에서는 숨김) · 가운데 그림 + 칩(`tab`) + 제목 + 설명 · 아래 점 + 버튼 줄 — 첫 장은 [다음]만 꽉 차게, 2장부터 [이전](soft, 한 장 앞으로) + [다음](마지막 장은 `doneLabel`), 비율 1 : 1.6
- 넘기기: 옆으로 밀기(터치 · 마우스) · [이전] · [다음] · 점 누르기 · 키보드 ← →. `prefers-reduced-motion` 이면 애니메이션 없음
- 그림(`visual`)은 틀이 `inert` · `aria-hidden` · `pointer-events-none`으로 감싸서 눌리지 않는다 → 실제 부품을 가짜 데이터로 넣어도 된다
- 그림 칸은 남는 높이만큼만 쓴다(넘치면 잘림). 360×640에서도 스크롤 없이 보이게 그림 높이를 정한다 (알바 버전: 휴대폰 모양 높이 300px · 낮은 화면에서는 줄어들고 아래가 흐리게)
- 매장 색(`--brand` · `--brand-soft`)은 바깥에서 정한다 (알바 버전은 `useCurrentStore` 의 매장 색)
- 본 기록 · 다 본 뒤 갈 곳은 화면이 정한다 (알바: `staffGuideSeen.ts`)
