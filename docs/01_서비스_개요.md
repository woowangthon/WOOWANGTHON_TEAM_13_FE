# 01. 서비스 개요

## 서비스 정의
개인 카페 **신입 알바생**이 매뉴얼을 쉽게 익히고, 근무 중 질문에 답을 받는 웹 앱 **crewBean** (c 소문자 · B 대문자, 11/10 회의 확정).
앱 안의 AI 채팅 기능 이름은 **AI 사수**다 (하단 탭 · "AI 사수에게 묻기"). 아래 "AI 사수"는 모두 이 채팅 기능을 말한다

## 누가 쓰나
| 사용자 | 하는 일 |
| --- | --- |
| 👔 사장님 | 매장을 만들고, 템플릿으로 매뉴얼·레시피를 등록하고, 알바생에게 초대코드를 준다 |
| 🙋 알바생 | 초대코드로 들어와 레시피를 포스기처럼 보고, 모르는 건 **AI 사수 채팅**에 묻는다 |
| 🤝 함께 | 인수인계를 텍스트 노트로 남기면 AI가 요약한다 |

## 핵심 가치
- AI 사수는 **우리 매장 매뉴얼·레시피만 근거로** 답하고 **출처를 보여 준다**
- 근거가 없으면 **지어내지 않고** "찾지 못했어요" → 사장님께 넘긴다
- 사장님 답은 매뉴얼로 쌓여 다음엔 AI가 답한다. 결정은 언제나 사람

## 작업 원칙
1. 기능 10개를 70%씩 만드는 것보다 **핵심 5개를 100%** 완성한다
2. **11/8까지 배포 URL**을 띄우고, 매 회의마다 실제로 동작하는 화면을 확인한다
3. 급여 같은 **계산은 코드**로 하고, 설명과 정리를 AI에게 맡긴다
