# 03. 사용자 시나리오 (요약)

원본: 팀 노션 / `00_AI사수_상세_사용자_시나리오.pdf` (v3, 11/2 회의 반영). 시연 매장 **달빛 카페**, 사장님 **박 사장님**, 알바생 **지은**(신입 · n잡) · **민수**(6개월 차).

## 공통
**C1. 로그인 · 역할 선택 (P0, 민지)** — 로그인 화면 [카카오로 시작하기] [Google로 시작하기] → Supabase 로그인 → `GET /me` → 매장이 없으면 "어떻게 시작할까요?" [☕ 매장을 운영해요] [🙋 매장에서 일해요]. 초대 링크(코드 포함)로 오면 역할 선택을 건너뛰고 바로 입장.

## 사장님 (나현 화면)
- **S1 매장 만들기 (P0)** — 매장 이름 · 주소 · 영업시간 → 홈에 다음 할 일(매뉴얼 → 레시피 → 알바생 초대). 사업자 인증은 P2.
- **S2 매뉴얼 등록 · 수정 · 삭제 (P0)** — 추천 템플릿 6개(📶 와이파이 · 🚻 화장실 · 🌅 오픈 순서 · 🌙 마감 순서 · 📦 배달·입고 · 💳 환불)가 점선 카드로. 누르면 예시 문구(플레이스홀더). [+ 직접 추가]. 삭제 시 "알바생 화면과 AI 사수 답변에서도 사라져요".
- **S3 레시피 등록 (P0) · 사진 스캔 (P1)** — 메뉴 템플릿(아메리카노 · 카페라떼 · 바닐라라떼 · 에이드 · 스무디 · 티) → 메뉴명 · 카테고리 · 재료·양 · 순서 · 메모. 카테고리 관리(커피 · 라떼 · 에이드 · 스무디 · 티 · 디저트). 사진 스캔은 AI 초안 → 읽지 못한 칸은 노란색 "확인 필요" → 사장님이 공개해야 보임.
- **S4 초대코드 발급 · 카톡 공유(P1) · 삭제 (P0)** — 알바생 추가(이름 · 시급, 최저시급 10,320원 미만 저장 불가) → 전용 코드(예: `K7P2QX`, 혼동 문자 0·O·1·I 제외) → [코드 복사] / [카톡으로 보내기]. 퇴사 시 [초대코드 삭제] → 즉시 차단, 기록은 보존.
- **S5 사장님 확인 필요 답변 (P1)** — AI가 답하지 못한 질문이 🔴 배지로 → 사장님 답 → 알바생 채팅에 "👔 사장님 답변" → AI가 "매뉴얼에 추가할까요?".
- **S6 추천 스케줄 (P1)** · **S7 급여 확인 (P1)** — 추천 1개 + 칸 조정 · 확정 / 직원별 급여(주휴 포함, 공휴일 가산 없음, "참고용").

## 알바생 (민지 화면)
- **A1 코드 입장 · 매장 전환 (P0)** — 초대 카드 [바로 입장하기] 또는 코드 입력 → "달빛 카페의 지은 님 맞나요?" → 알바 홈. 두 번째 매장 코드를 넣으면 상단에 **매장 전환 "☕ 달빛 카페 ▾"**. 전환하면 매뉴얼 · 레시피 · 채팅 · 인수인계 · 근무가 **선택한 매장 것만**. 코드 5회 실패 시 10분 잠금.
- **A2 레시피 · 매뉴얼 보기 (P0)** — 레시피 탭은 **포스기처럼**: 위에 카테고리 탭, 아래 메뉴 버튼 격자 → 레시피 카드(재료 · 양 표 + 순서 + 메모). 검색 지원. 매뉴얼은 바둑판 카드, 새 카드는 NEW.
- **A3 AI 사수 채팅 (P0) ⭐** — 상단 "달빛 카페 매뉴얼 기준으로 답해요" + 자주 묻는 질문 칩.
  - "딸기라떼 딸기청 몇 스푼이야?" → "3스푼이에요…" + **📄 출처: 레시피 › 딸기라떼** (누르면 원본 카드)
  - 근거 없음("우산 빌려줘도 돼?") → "매뉴얼에서 찾지 못했어요. 제가 지어내지 않을게요" + **[사장님께 물어보기]**
  - 매장 업무와 무관한 질문 → "매장 업무 질문에만 답할 수 있어요". n잡이면 다른 매장 매뉴얼은 절대 섞지 않는다
- **A4 인수인계 (P0)** — 텍스트로 작성 → **AI 요약**(💳 외상 · 📦 재고 · 🔧 기타 태그 + 체크리스트) → 다음 근무자 홈 맨 위 "📌 오늘의 인수인계 3건" + 3줄 요약 → 처리하면 ☑. [특이사항 없음] 버튼. 출근 전 알림은 P3.
- **A5 근무 가능 시간 · 내 근무표 (P1)** — 달력에서 가능/불가 칠하기, 메모, 희망 횟수 → 확정 후 내 근무 강조.
- **A6 예상 급여 (P1)** — 확정 근무 × 시급 + 주휴수당(주 15시간 이상인 주만) = 합계(참고용), 주별 근거 + AI 쉬운 설명.
