| P0 | 매장 생성, 알바 초대코드 발급 · 삭제 | 사장 | 11/8 | 나현 | 알바는 코드 입력으로 매장 연결(민지) |
| P0 | 매뉴얼 · 레시피 등록 · 수정 · 삭제 (템플릿 + 직접 작성) | 사장 | 11/8 | 나현 | 고정 템플릿 5~6개, 레시피는 카테고리 지정 |
| P0 | 매뉴얼 · 레시피 조회 | 알바 | 11/8 | 민지 | 레시피는 **포스기처럼 카테고리별** |
